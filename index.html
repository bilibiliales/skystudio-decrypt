功能特点

Sky Studio乐谱解密解析工具是一个纯静态、单页面的浏览器工具，面向需要处理 Sky Studio TXT 或 MusicXML 乐谱的玩家、制谱者和乐谱整理者。它可以解密 TXT 乐谱，解析 MusicXML 节拍，用 15 键或 C2–C7 的 61 键钢琴预览，并支持脚本、MP3、简谱图片、单文件和 ZIP 导出。

  • 支持 Sky Studio TXT 加密乐谱文件的本地解密。
  • 支持 MusicXML 节拍解析、61 键钢琴预览和按音高动态生成 A1、A2……键位脚本。
  • MusicXML 可在“钢琴”和“明亮钢琴”两种音色之间切换。
  • 支持键盘可视化和音频播放，方便检查节奏。
  • 支持代码、简谱、时间轴和方格谱等预览方式。
  • 支持直接导出 MP3 音频，不需要录制预览声音。
  • 支持多文件选择、批量下载和 ZIP 导出。

使用方法

  1. 准备一个或多个 Sky Studio TXT、MusicXML 或 XML 乐谱文件。
  2. 点击上传区域，或将乐谱文件拖入上传框。
  3. 在文件列表中选择乐谱，检查名称、作者、BPM、拍子、加密状态和音符数量。
  4. TXT 使用 15 键布局预览；MusicXML 使用 C2–C7 的 61 键钢琴预览，并显示动态脚本键位数量。
  5. 按需要下载源文件、脚本或 MP3；TXT 还可导出简谱图片、复制代码，或生成 ZIP。

如何把 Sky Studio 音乐导出为 MP3？

上传并转换支持的 Sky Studio TXT 或 MusicXML 乐谱后，点击“导出MP3”。页面会根据音符时间线，在浏览器中离线渲染整首曲子的音频，再编码成 MP3 文件下载。MusicXML 会使用当前选择的钢琴音色。这个过程不需要麦克风权限、录屏或系统声音录制。

为了得到更稳定的结果，建议先预览一次并确认 BPM、歌曲信息、音色和节奏正常，再导出最终 MP3。

支持的文件类型

支持 .txt、.musicxml 和 .xml 乐谱文件。TXT 文件支持解密、15 键预览、简谱和音频导出；partwise MusicXML 支持 divisions、休止符、和弦、连音线、多声部和速度变化，并可在 C2–C7 的 61 键范围内预览与导出 MP3。超出该范围的音符仍会保留在动态键位脚本中。

关于 Sky Studio 加密

Sky Studio 加密通常用于以非明文形式分享或保存乐谱数据。对玩家来说，这会让预览旋律、确认 BPM、归档歌曲或转换记谱方式变得不方便。本工具会在浏览器中处理支持的编码方式，把数据重建成可预览、可下载、可导出的乐谱结构。

隐私政策

本工具部署在 GitHub Pages 上，是纯静态网页，不提供账号登录、表单提交、数据库存储或服务端文件上传功能。你选择的 TXT 或 MusicXML 乐谱文件由浏览器本地读取和处理，解密、转换、预览和导出都在当前浏览器环境中完成。

为了播放预览音效，页面会加载音频文件；导出 MP3 时，页面会按需加载浏览器端 MP3 编码器。这些静态资源请求不包含你上传的 TXT 乐谱内容。工具可能使用浏览器本地存储保存界面设置、背景图设置或工作列表，你可以通过浏览器设置清除站点数据。

常见问题

什么是 Sky Studio 加密文件？

它通常是一个经过编码的 TXT 乐谱文件，歌曲信息和音符事件不是普通可读文本。需要先解密或解析，才能预览、转换或导出。

工具会上传文件吗？

不会。乐谱文件由浏览器本地读取和处理，不会被本项目上传到转换服务器。

可以批量解密文件吗？

可以。文件选择器支持多个 TXT 文件，你可以选择文件、下载选中结果，或生成 ZIP 压缩包。

导出 MP3 需要录音权限吗？

不需要。MP3 导出使用离线音频渲染和浏览器端编码，不调用麦克风。

源码是开源的吗？

是。项目托管在 bilibiliales 的 skystudio-decrypt GitHub 仓库中。️ 郑重提醒：本项目完全免费且开源，绝无任何付费渠道。市面上任何收费售卖的版本均为盗版或诈骗，请注意甄别，谨防上当！

Features

Sky Studio Music Decrypt Tool is a static single-page browser utility for Sky Studio TXT and MusicXML scores. TXT sheets support decryption, preview, notation, and MP3 export. MusicXML scores add a C2–C7 61-key piano, two timbres, MP3 export, and dynamically keyed scripts.

  • Browser-side Sky Studio TXT decryption for supported encrypted sheets.
  • Rhythm-aware MusicXML parsing with a 61-key piano and dynamically generated script keys.
  • Normal and bright piano timbres for MusicXML preview and MP3 export.
  • Online preview with keyboard visualization and audio playback.
  • Code, simplified notation, timeline, and grid-style preview modes.
  • Direct MP3 export without recording preview playback.
  • Batch download and ZIP export for multiple files.

How to use

  1. Prepare one or more TXT, MusicXML, or XML score files.
  2. Click the upload area or drag score files into the page.
  3. Select a sheet from the file list and check its metadata, BPM, encryption status, and note count.
  4. Preview TXT music with the 15-key layout or MusicXML with the C2–C7 piano keyboard.
  5. Download source files, scripts, or MP3 audio. TXT sheets can also export notation and generated code.

How to export Sky Studio music to MP3?

To export Sky Studio music to MP3, upload a supported TXT or MusicXML sheet and click 导出MP3. The tool renders the note timeline locally with the current key or piano samples and encodes it in the browser; it does not record your microphone, screen, or system audio.

Preview the sheet first and confirm that the BPM, metadata, and rhythm are correct. The exported MP3 is useful for saving a playable audio version, sharing a quick preview, or checking an arrangement without asking the user to record playback manually.

Supported file types

The tool accepts Sky Studio .txt sheets and partwise .musicxml / .xml scores. TXT files support decryption, 15-key preview, notation, and audio export. MusicXML supports rhythm-aware scripts plus C2–C7 61-key preview and MP3 export; pitches outside that audio range remain available in the generated script.

About Sky Studio encryption

Sky Studio encryption stores sheet data in a form that is not immediately readable as normal note text. This can make it difficult to preview a melody, verify BPM, archive a song, or convert a score into another format. This tool handles supported formats in the browser and rebuilds the data into a usable music structure.

Privacy Policy

This project is a static GitHub Pages site. It has no user accounts, form submission, database, or server-side file upload workflow. Selected TXT and MusicXML sheets are read and processed locally by your browser.

The page loads static audio and interface assets. MP3 export loads a browser-side MP3 encoder on demand to convert locally rendered audio into a downloadable file. Your sheet content is not uploaded by this project. Local browser storage may be used for interface settings, background image settings, or the local working list.

FAQ

What is a Sky Studio encrypted file?

It is usually a TXT sheet whose song metadata and note events are encoded rather than written as readable note text.

Does the tool upload files?

No. Selected TXT sheets are processed locally in the browser and are not uploaded by this project.

Can I batch decrypt files?

Yes. You can select multiple TXT files, download selected converted results, or generate a ZIP archive.

Does MP3 export need microphone permission?

No. MP3 export uses offline audio rendering and browser-side encoding, not microphone recording.

Is the source code open source?

Yes. The project is available in the bilibiliales skystudio-decrypt GitHub repository.
