# skystudio-decrypt
This repository contains a webpage for decrypting Sky Studio music score files, and this webpage also has a feature for previewing the scores online.

>The code shouldn't have any `&` characters. This is to make sure it can be embedded as code on websites, like [WordPress](https://wordpress.com).

#### This repository uses code from the following repositories:
https://github.com/tokisakiyuu/skypiano
https://github.com/NikoYOYO/sky-decrypt-tool
